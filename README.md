Este repositório guarda o meu trabalho final da disciplina de Laboratório de Programação 1 na Universidade Federal de Santa Maria (UFSM). 
O objetivo do trabalho era implementar, em linguagem C, um jogo de eliminação dos quadradinhos ao empilhar peças de uma mesma cor em uma mesma coluna. 
O jogo salva os recordes em um arquivo de forma decrescente, de modo que o jogador com a maior pontuação fique no topo.
