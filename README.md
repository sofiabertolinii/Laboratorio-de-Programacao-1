# 🎮 Trabalho Final — Laboratório de Programação I (UFSM)

Este repositório contém o **trabalho final da disciplina de Laboratório de Programação I** na Universidade Federal de Santa Maria (UFSM).

---

## 🧩 Descrição do Projeto

O objetivo do trabalho foi desenvolver, em linguagem C, um **jogo de eliminação de quadradinhos**, no qual o jogador deve empilhar peças de mesma cor em uma mesma coluna para realizar eliminações e acumular pontos.

---

## 🕹️ Funcionamento do Jogo

- O jogador movimenta e posiciona peças em colunas
- Quando uma coluna contém peças da mesma cor empilhadas, ocorre a eliminação
- O objetivo é maximizar a pontuação antes do término do jogo

---

## 🏆 Sistema de Recordes

O jogo possui um sistema de armazenamento de recordes:

- As pontuações são salvas em arquivo
- Os recordes são mantidos em **ordem decrescente**
- O jogador com maior pontuação fica no topo da lista

---

## 🎯 Objetivo Acadêmico

Este trabalho tem como objetivo aplicar conceitos de:

- Lógica de programação em C
- Manipulação de matrizes e estruturas de controle
- Manipulação de arquivos
- Organização de lógica de jogo
- Implementação de sistemas de pontuação e ranking
